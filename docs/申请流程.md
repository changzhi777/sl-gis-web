# 地图服务认证申请流程

> 适用：SL-GIS 大屏（政务项目 · 旗县水利局）
> 用途：天地图瓦片底图（tk）+ 高德乡镇行政区边界（key）
> 更新：2026-09-10

---

## 一、天地图（国家官方 · 政务项目首选）

### 1.1 注册账号

1. 打开 [console.tianditu.gov.cn](https://console.tianditu.gov.cn)
2. 注册：手机号 + 验证码
3. 登录后进入「控制台」

### 1.2 个人认证（前置，必做）

1. 控制台 → 账号设置 → 实名认证
2. 类型选「个人」：身份证正反面照片 + 手持照
3. 审核：1-2 个工作日

### 1.3 企业/政务认证（本项目需要）

> 政务大屏项目用**政务认证**，权益：浏览器端 key 日配额从个人 1000 次/日提升到 **10 万次/日以上**，且政务项目审计合规。

1. 控制台 → 账号设置 → **实名认证** → 升级认证
2. 类型选「单位认证」→ 提交材料：

| 材料 | 要求 |
|---|---|
| 营业执照 或 统一社会信用代码证 | 彩色扫描件，加盖公章 |
| 经办人身份证 | 正反面 |
| 授权委托书 | 天地图模板下载，单位盖章 |
| 项目说明 | 「SL-GIS 旗县县域统管农村供水管理平台 · 水利局政务大屏项目」一句话 + 合同/立项文件号（如有） |

3. 审核：**3-5 个工作日**（政务类可打客服 010-53856291 催办）
4. 通过后账号标记变为「认证单位」

### 1.4 创建浏览器端 key（tk）

1. 控制台 → 开发资源 → 应用管理 → **创建应用**
2. 应用名称：`sl-gis-dashboard`
3. 类型：**浏览器端**
4. 域名白名单：`nanoai.fun`（一行一个，支持 `*.nanoai.fun`）
5. 提交 → 复制生成的 **tk**（32 位字符串）

> ⚠️ 浏览器端 tk 本来就是公开可见的（前端 URL 带它），安全性靠**域名白名单**控制 — 只允许你的域名调用。

### 1.5 配额参考

| 认证级别 | 浏览器端日配额 | 说明 |
|---|---|---|
| 个人 | 1,000 次/日 | 开发调试够用 |
| 单位认证 | **10 万+ 次/日** | 大屏长期运行 |

### 1.6 配置进项目

```bash
# sl-gis-web/.env.local（不入 git）
VITE_TIANDITU_TK=你的32位tk
```

pnpm build 时 Vite 自动注入。大屏运行时每次刷新按需拉取当前视野的卫星瓦片（~20-60 张/次，远低于配额）。

## 二、高德开放平台（乡镇边界 API）

### 2.1 企业认证（已有 ✅）

企业账号已完成认证 — 权益：Web 服务 API 50 次/秒、日配额充足。

### 2.2 创建 Web 服务 key

1. 打开 [lbs.amap.com](https://lbs.amap.com) → 控制台 → 应用管理 → 我的应用
2. 「创建新应用」：名称 `SL-GIS`，类型：出行
3. 应用下「添加 key」：
   - key 名称：`sl-gis-township-boundary`
   - 服务平台：**Web 端**（注意：不是 Web 端 JS API — 是「Web 服务」）
4. 复制生成的 **key**（32 位）

### 2.3 调用乡镇边界（一次性数据获取）

行政区查询 API 在 `extensions=all` 时返回**边界坐标串**（polyline）：

```
https://restapi.amap.com/v3/config/district?keywords=152524&subdistrict=3&extensions=all&key=你的key
```

- 苏尼特右旗 → 下一级 3 镇 4 苏木（高德口径），逐个子级可拿边界
- ⚠️ 高德**乡镇级边界覆盖不全**（内蒙古苏木乡镇部分缺失）— 脚本会逐个尝试并报告哪些成功

### 2.4 一键执行（key 走本地环境变量，不进代码/对话）

```bash
cd sl-gis-web
AMAP_KEY=你的key node scripts/fetch-townships.mjs
```

输出 `public/geo/townships.json` — 前端 TownshipLayer 自动加载。

### 2.5 备选：AreaCity 数据集（若高德乡镇边界缺失）

- 来源：[xiangyuecn/AreaCity-JsSpider-StatsGov](https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov)（6871★，2026-04 更新）
- 下载：[area.city](https://area.city/) 官网 → 数据下载 → 选「旗县下的乡镇级」→ GeoJSON 格式
- 免费（需注册 OS 账号）；下载后放到 `public/geo/townships.json`（字段对齐 GeoJSON FeatureCollection）

## 三、合规要点速记

| 平台 | 运行时加载 | 离线下载 | 政务项目 |
|---|---|---|---|
| **天地图** | ✅ 认证后明确授权 | ⚠️ 需单独申请 | ✅ **官方推荐**（自然资源部背景） |
| **高德** | ✅ 企业认证 JS API 合规 | ❌ 不在开放平台授权内 | 常见但审计需说明来源 |
| **GeoD/BIGEMAP 工具** | — | ⚠️ 工具声明"需图源方授权" | 天地图源在 GeoD 中配置 tk 即可 |

> **本项目策略**：底图瓦片走天地图（合规+政务背书）；高德仅用于一次性拉取乡镇边界数据（脚本本地跑，key 不入库）。

## 四、故障排查

| 症状 | 原因 | 修 |
|---|---|---|
| 天地图瓦片 403 | 域名白名单没加 nanoai.fun | 控制台 → 应用管理 → 编辑 key → 加域名 |
| 天地图配额超限 | 个人认证 1000 次/日 | 升级单位认证 |
| 高德 INVALID_USER_KEY | key 类型错（建成了 JS API） | 重建成「Web 服务」类型 |
| 高德乡镇边界缺失 | 内蒙古苏木乡镇覆盖不全 | 换 AreaCity 数据集（§2.5） |
| township.json 加载 404 | 文件没进 dist | 确认放 `public/geo/`（vite 自动拷贝） |
